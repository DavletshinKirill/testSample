### Реализовать консольное приложение, осуществляющее запуск пяти потоков. Каждый поток должен при старте увеличить значение общего для всех потоков счетчика на единицу и вывести значение на экран. Выводимые на экран значения должны идти строго в порядке увеличения и не повторяться.

### Для запуска необходимо запустить build.bat, после чего запустить main.exe в папке 
### .\build.bat
### .\bin\main.exe
