### Описать структуру «Book», содержащую параметры книги:
- Название;
- Автор;
- Год издания;
- Кол-во страниц.

### Написать функцию, подсчитывающую суммарное количество страниц во всех книгах. В качестве параметра функции должен передаваться указатель на массив книг.

### Для запуска необходимо запустить build.bat, после чего запустить main.exe в папке 
### .\build.bat
### .\bin\main.exe
